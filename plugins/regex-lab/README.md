# 正则实验场

写正则的地方：边写边看它匹配到哪、每个括号抓到了什么、替换之后长什么样。
算不完的表达式会被自动中断，不会把整个应用拖死。

## 给谁用

经常要写正则的人。场景通常是三种：从一大段日志里捞出想要的行、把一段文本清洗成
能用的样子、写一条校验规则确认它真的能拦住该拦的东西。

难点很少是「不会写」，而是「写完不知道对不对」—— 这个插件解决的就是后半句。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 实时匹配 | 改动表达式或文本之后自动重算，不用反复点按钮 |
| 高亮预览 | 把命中的部分标出来；也可以只看某一个捕获组抓到了哪一段 |
| 捕获组明细 | 每一处匹配列出序号、位置、匹配内容，以及每个组的内容与起止位置 |
| 替换预览 | 写替换内容（$1、$2、$& 这些都能用），立刻看到替换后的完整结果 |
| 命名组对照 | 用 (?<名字>…) 写的组会显示成「第 3 组（名字）」，$<名字> 与 $3 一眼对得上 |
| 表达式库 | 24 条常用表达式，分「常见校验 / 提取 / 查找 / 清理 / 开发 / 反面教材」六组，点一下就载入 |
| 保存自己的表达式 | 把自己常用的存下来，下次直接取用 |
| 记住草稿 | 表达式、测试文本、替换内容都留在本机，重开应用还在 |

表达式库里每一条都配了一段能看出效果的示例文本，载入时一起填好 ——
空手试正则最难的一步是先得有一段能匹配的文本。

## 怎么用

1. 在最上面写下正则表达式。左边的输入框里写表达式，右边那排小方块是开关。
2. 在左下角的框里粘贴要测试的文本。
3. 右边会立刻给出结果。三个视图用上方的标签切换：
   「匹配高亮」看命中位置，「捕获组明细」逐条看每个组，「替换预览」看替换结果。
4. 想不出表达式，就切到「表达式库」挑一条；想留住自己写好的，也在那里保存。

高亮有多个捕获组时，可以用「高亮范围」下拉把范围缩小到某一个组 ——
排查「到底哪一段被那个括号吃掉了」时这是最直接的办法。

## 那排小开关

这是唯一需要先看懂的地方。点一下开关就打开，再点一下关掉。

| 开关 | 名字 | 打开之后 |
| --- | --- | --- |
| g | 全局 | 找出全部匹配；关掉它只找第一个 |
| i | 忽略大小写 | A 与 a 视为同一个字符 |
| m | 多行 | ^ 与 $ 分别匹配每一行的开头与结尾，而不是整段文本的首尾 |
| s | 点号含换行 | . 也能匹配换行符 |
| u | Unicode | 按完整码点解释，\p{...} 这类写法需要它 |
| v | Unicode 集合 | u 的增强版，两组不能同时开，本插件会自动替你换掉另一个 |
| y | 粘连 | 只从上一处结束的位置继续匹配 |
| d | 记录组位置 | 额外记录每个捕获组的起止位置 |

d 即使不打开，本插件在内部也会把它加上 —— 因为「第 2 组在第 14–18 个字符」这类
信息需要它。d 只增加位置记录，不改变匹配结果，所以你不会看到任何差别。

## 算不完的表达式会被中断

有些表达式在长文本上会慢到离谱。典型例子是「量词套量词」，比如 (a+)+ 遇到一长串 a
后面跟一个不匹配的字符：它要尝试的组合数随文本长度指数增长，几十个字符就能让一次
匹配跑上几分钟。

这种表达式最麻烦的地方在于它不是「算得慢」，而是「停不下来」—— 在浏览器主线程上跑，
整个应用会一起卡死，连停止按钮都点不动。

所以这里的计算放在后台线程里进行，超过 1.2 秒直接中断，并告诉你几乎可以肯定是回溯
爆炸、以及通常该怎么改。表达式库里那条「反面教材」就是给你试这个的。

中断也可能误伤：一条确实很慢但最终能算完的表达式同样会被截断。取舍是刻意选的 ——
让界面卡死比让一次计算失败糟得多。

## 文本长度的几档限制

这些都是为了「不把界面卡死」，而不是省事：

| 情况 | 行为 |
| --- | --- |
| 文本超过 10 万字符 | 不再随输入自动计算，改完点一次「计算」 |
| 文本超过 200 万字符 | 明确拒绝，并说明超出一次能处理的范围 |
| 匹配超过 5000 处 | 只收集前 5000 处，并标注已达到上限 |
| 高亮超过 800 处 | 只画前 800 处，其余可以在「捕获组明细」里逐条看 |
| 明细超过 300 行 | 只列出前 300 行 |

还有一档只在特殊环境下出现：如果当前环境不允许创建后台线程，本插件会自动改用主线程
执行，那时可处理的文本长度收紧到 2 万字符 —— 主线程上无法中断一条正则，超过这个长度
不执行反而是负责任的做法。这种情况会在插件日志里留一条记录。

## 用到的权限

只有一项：

| 权限 | 用来做什么 |
| --- | --- |
| storage | 记住你的表达式草稿、测试文本、替换内容、界面设置，以及你自己保存的表达式 |

没有申请网络相关的权限 —— 表达式与文本都在你的电脑上计算，不发送到任何地方。
也没有申请文件相关的权限 —— 本插件不读写任何文件。

关于复制按钮：它用的是应用界面自带的剪贴板接口（写一段文字到系统剪贴板），
不经过宿主提供的剪贴板服务，因此这里没有申请 clipboard 权限。若该环境不允许，
复制会失败并提示你手动选中复制，而不是静默什么都不做。

## 边界

写在前面，免得你在某个时刻以为它坏了：

- 表达式与文本只在这台电脑上算，不联网，也不写入日志。
- 本插件不是 HTML 解析器，也不是语法分析器。内置的「HTML 标签」那条只是一个
  正则匹配，遇到嵌套与不规范的写法会给出看起来奇怪的结果，那属于正则的固有边界。
- 替换预览与匹配使用同一组开关：没打开 g 时只替换第一处。这是刻意的，
  免得你以为已经全部替换了。
- 换行按原样显示。表达式里的点号默认不匹配换行 —— 需要它匹配换行就打开 s 开关。
- 高亮与明细都只列出前若干条（见上一节），这不是漏掉了，是上限。
