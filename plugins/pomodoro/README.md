# 番茄工作钟 —— Modulith 示例插件

专注 / 短休息 / 长休息循环计时，到点提醒你。

它示范的是**「插件不只是页面」**：计时与提醒的核心放在 React 之外，因此你从未打开过
这个模块，到点照样会收到通知。

## 功能

| 功能 | 怎么用 |
| --- | --- |
| 开始 / 暂停 | 主界面的「开始」「暂停」「继续」 |
| 跳过当前阶段 | 「跳过」 |
| 调时长 | 专注（默认 25 分）、短休息（5 分）、长休息（15 分） |
| 长休息间隔 | 每完成 4 个专注进入一次长休息 |
| 自动衔接 | 可分别设置「休息结束自动开始专注」与「专注结束自动进入休息」 |
| 提醒 | 阶段结束时发一条应用内通知；可在设置里关掉 |
| 提示音 | 默认提示音由 WebAudio 现场合成；也可以「导入音频」换成自己的文件，或静音 |
| 今日统计 | 今日完成数与累计完成数 |
| 记录这一段在做什么 | 每段专注可以留一句备注，可留空 |

**计时在后台运行，不需要停在这一页。** 关掉窗口里的其它模块、甚至切到别的模块去，
到点都会收到通知。

## 申请的三项权限

| 权限 | 用来做什么 |
| --- | --- |
| `storage` | 保存设置、计时状态与今日统计 |
| `notification` | 阶段结束时发应用内通知。没有它不会有任何提醒 |
| `filesystem-read` | **只在你主动「导入音频」时使用**：读你选中的那个音频文件。不导入就完全用不到 |

`filesystem-read` 看着比实际宽，值得说清楚：这个插件不会去读你的文件，它只能在你在
系统文件对话框里亲手选中一个音频文件之后，读取那一个文件的内容。默认提示音是现场合成的，
因此**不导入任何文件它也能完整工作**。

## 实现上值得注意的几点

### 计时核心放在 React 之外

番茄钟的全部意义是「你去干别的，到点提醒你」。如果计时挂在组件里，**从未打开过这个模块
就什么都不会发生**：

```js
var core = { settings, timer, stats };        // 模块级状态
window.setInterval(tick, 200);                // 模块级心跳，与是否挂载无关
React.useEffect(function () { return subscribe(forceRender); }, []);  // 界面只是订阅者
```

两个与之配套的决定：

- **剩余时间始终由 `endsAt` 与当前时间算出**，而不是每个 tick 减一次。后者会在窗口被
  后台节流、系统休眠时越走越慢，而用户对番茄钟的期待是「墙上时钟走了 25 分钟」。
- **只在显示的秒数变化时才通知订阅者**，否则每秒会触发五次重渲染。

### 提示音不需要打包音频资源

默认提示音是**用 WebAudio 现场合成**的（两个正弦音，上行 / 下行区分去向），因此插件包里
没有任何音频文件。用户想换，再用 `ctx.audio` 导入自己的。

浏览器的自动播放策略要求音频先在手势里「解锁」，所以它在用户点「开始」时建立并
`resume()` 一个 `AudioContext` —— 等到 25 分钟后到点才去创建，播放会被直接拒绝。

### 存储格式向前兼容

设置、计时状态、统计各占一个键，读取时逐字段兜底。**用户的数据只有一份，读的时候容错
比写的时候谨慎更重要** —— 改版不该让老用户的统计消失。

### 不声明权限时会怎样

通知与音频都会降级：`ctx.notifications.isAvailable()` 返回 false，界面据此提示
「未获得通知权限，通知不会发出」，而不是静默地什么都不做。这样作者不必靠控制台
才知道自己漏了权限。

## 目录结构

```
pomodoro/
├── manifest.json      清单（storage / notification / filesystem-read）
├── index.js           手写 IIFE，无构建步骤
├── index.css          插件自带样式
├── icon.svg           图标（SVG 文本会被直接内联渲染）
├── README.md          会显示在插件详情抽屉里
└── LICENSE            MIT
```

打包与发布见[发布流程](../../docs/发布流程.md)：`node scripts/build.ts` 会把 `plugins/` 下的每个
插件打成 `dist/<插件 ID>-<版本>.lcp` 并重新生成 `index.json`。**索引改了必须重新签名** ——
客户端会验签，签名与索引对不上时市场对所有人打不开。
