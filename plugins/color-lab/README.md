# 颜色与对比度

看清一种颜色的各种写法，由它推出一整色阶，并按 WCAG 标准算出它和背景的对比度是否达标。

## 给谁用

要定配色、要检查文字能不能看清的人。典型场景：设计给了一个色值，想知道它配白底到底
够不够清楚；想从品牌色扩出一整套调色板；想确认两种颜色对色盲用户是否还分得开。

## 怎么用

上面有两个输入框：左边是主色（也就是文字色），右边是背景色。两个都可以手输，
也可以点旁边的色板用系统取色器挑。中间那个「对调」把两者互换。

下面分两块：

左边一块是这个颜色的信息 ——

- 它的各种写法：十六进制（含透明度）、RGB、RGBA、HSL、HSLA，以及现代 CSS 用的 OKLCH。
  每一行都能一键复制。
- 以它为锚点的十档色阶（50 到 900）。点任意一格就把它变成主色；
  色阶里带强调色描边的那一格是锚点档，它与主色完全相同。
- 三种色盲类型下它看起来是什么颜色。用来判断「这个颜色和另一个颜色在色盲眼里还分得开吗」。

右边一块是对比度 ——

- 一段用当前两个颜色实际排版出来的预览。好不好看是一眼的事，不必只看数字。
- 对比度比值，以及按 WCAG 标准逐项的通过情况。
- 几个快捷操作：换成白字或黑字（会显示各自的对比度）、自动把颜色调整到 4.5:1 或 7:1。
  「自动调整」会在同一个色相上加深或提亮，尽量保住原来的颜色倾向，而不是直接变成纯黑。

## 对比度的几个门槛

| 场景 | 要求 | 说明 |
| --- | --- | --- |
| 正文 AA | 4.5:1 | 小于 18.66px 的常规文字 |
| 正文 AAA | 7:1 | 更严格的正文标准 |
| 大字 AA | 3:1 | 18.66px 以上的粗体，或者 24px 以上的文字 |
| 大字 AAA | 4.5:1 | 更严格的大字标准 |
| 界面元素 | 3:1 | 图标、输入框描边、图表这类非文字内容 |

## 能接受的写法

`#4f46e5`、`#fff`、`#4f46e580`（末两位是透明度）、`4f46e5`（省略井号也行）、
`rgb(79,70,229)`、`rgba(79,70,229,0.8)`、`hsl(243,75%,59%)`、`hsla(243,75%,59%,0.8)`，
以及常见颜色名（tomato、steelblue 之类）。

本工具只收常用颜色名，不是完整的 CSS 颜色名表。写不出来的颜色名会明确告诉你读不出来，
并给出现在能用的几种写法。

## 用到的权限

只有一项：

| 权限 | 用来做什么 |
| --- | --- |
| storage | 记住你输过的两个颜色、色阶锚点档与变量名前缀 |

没有申请任何其它权限 —— 这里全部是纯数学计算，不联网、不读写文件。

## 边界

写在前面，免得你在某个时刻以为它算错了：

- 半透明颜色会先与背景合成，再算对比度。因为眼睛看到的是合成后的颜色 ——
  直接拿通道值去比会把 `rgba(0,0,0,0.6)` 这类文字算得过暗或过亮。
  如果背景本身也是半透明的，会按「页面底色是白的」来合成。
- 相对亮度那一行显示的是按不透明计算的值，它不含透明度的影响，和上面那条并不矛盾。
- 色阶是从一个颜色推导出来的：浅端往近白走、深端往近黑走，锚点档精确等于主色。
  它不会替你保证每一档都好看，只是保证它们同源、顺序正确。
- 色盲模拟是近似算法（在线性 RGB 上做矩阵变换），用来做自查，不能当作医学判断。
- 对比度是按 WCAG 2.x 的公式算的。WCAG 3 还在草案阶段，算法与门槛都可能变化。
- 颜色名只覆盖常用的一批，完整的 CSS 命名色表没有收录。
