# 概率实验室 —— Modulith 插件

用可复现的随机试验核对直觉。

三件事，三个标签页：

| 标签页 | 回答的问题 |
| --- | --- |
| **批量统计** | 跑很多次之后，命中率到底会不会收敛到设定概率？偏多少算正常？ |
| **一发入魂** | 只抽一次、抽很多轮，这次的「运气」有多离谱？ |
| **理论分布** | 在同样的参数下，精确的二项分布本来该是什么样？ |

所有计算都在本机内存里完成，不联网、不上报、不生成密钥。

## 功能

- **分轮模拟**：轮数 × 每轮次数，逐轮记录命中数、本轮命中率与累积命中率。
- **收敛曲线**：累积命中率折线 + 设定概率虚线 + 置信水平对应的「正常波动范围」。
  范围不是等宽的 —— 每轮的标准误不同，因此它会随着轮数增加而收窄，这正是大样本的性质。
- **逐轮视图**：切换到「每轮命中率」可以直接看每一轮单独的抖动。单轮样本小，抖动本来就大；
  把它和波动范围放在一起，才知道「看起来的异常」有多少只是噪声。
- **统计汇总**：总试验次数、命中 / 未命中、理论命中、偏差、标准误、z 分数、置信区间与判定。
- **每轮明细表**：轮号、命中、未命中、本轮命中率、累积命中率。可复制为 CSV。
- **单发实验**：测试轮次 × 每次 1 抽，给出命中率、z 分数、双尾 p，以及一句人话结论；
  另外画出命中 / 未命中占比和前 200 次的逐次结果（实心 = 命中）。
- **精确二项分布**：给定 n、p、k，算出 P(X = k)、P(X ≤ k)、P(X ≥ k)、期望、标准差、众数，
  以及均值 ±1σ 的整数区间与它的实际覆盖概率；柱状图里深色那根就是 k。
- **可复现**：种子留空时自动生成一个、填回输入框并提示；同一个种子的结果逐位一致。
- **可中断**：最多 1 亿次试验，切成约 12ms 一片执行，界面不会卡住，随时可以取消。
- **记住输入**：三个标签页的参数、置信水平都会保存，重开窗口还在。
- **快捷键**：`Ctrl / Cmd + Enter` 运行当前标签页（只在模块可见时生效）。

## 怎么用

### 批量统计

1. 填 **轮数**、**每轮次数**、**命中概率（%）**。默认 10 × 1000 × 30%，几毫秒就跑完。
2. **随机种子**可以留空。留空时点一次运行会生成一个种子并填回去，方便之后再复现。
3. 点「开始批量实验」。大的试验量会显示进度条与「取消」。
4. 看汇总卡片里的 **z 分数** 与 **置信区间**；`|z| ≤ 1.96`（95% 档）就是「在正常波动内」。
5. 想看细节就切换到「每轮命中率」，或者展开下面的明细表。

### 一发入魂

1. 填 **测试轮次**（每次只抽 1 次）、**命中概率**、可选的种子。
2. 点「一发入魂」。
3. 结果里有实际命中率、理论命中次数、偏差、标准误、z 分数与双尾 p。
   p 小于 5% 大致就是「这么偏的结果，纯随机时很少见」。
4. 「这次的手气」会把数字翻译成一句话；下面的顺序带按抽取顺序显示前 200 次。

### 理论分布

1. 填 **试验次数 n**（1–5000）、**命中概率**、**命中次数 k**（0–n）。
2. 不用点运行 —— 这是精确计算，改数字就出结果。
3. 想看「这么多轮如果真跑一遍会怎样」，点「用这组参数模拟」，参数会被带到批量统计页。

## 这些数字都是什么

| 名称 | 定义 | 怎么读 |
| --- | --- | --- |
| 标准误 SE | `√(p(1−p)/n)` | 命中率的抽样波动尺度；n 越大越小 |
| z 分数 | `(实际命中率 − p) / SE` | 离期望有几个标准误远 |
| 置信区间 | `命中率 ± z* × SE`（截断到 0–100%） | z* 由置信水平决定：90% → 1.645，95% → 1.960，99% → 2.576 |
| 正常波动范围 | 每轮 `p ± z* × √(p(1−p)/(round × 每轮次数))` | 图上的带状区域，越往右越窄 |
| 双尾 p | `P(\|Z\| > \|z\|)`，正态近似 | 这个偏差在纯随机假设下的出现概率 |
| 判定 | `\|z\| ≤ z*` 为正常 | 超出只说明「少见」，不等于「机制被改过」 |

**正态近似有边界，这里如实写出来。** n 很小、或 p 接近 0 / 1 时，区间会偏窄、判定会偏乐观；
理论分布页就是用来核对这一点的。区间两端做了 0–100% 截断，所以极小样本下会看到
`[0.00%, 0.00%]` 这类退化结果，那是近似失效，不是 bug。

## 种子与可复现

随机数不是 `Math.random`，而是一个 32 位状态的 PRNG（mulberry32）。这意味着：

- **同一种子 → 同一条序列 → 同一份结果**，逐位一致；
- 种子范围是 `0 – 4,294,967,295`，留空时用 `crypto.getRandomValues` 生成；
- 它**不是密码学安全的随机数**。不要用它生成密钥、口令或任何安全相关的值 ——
  这个工具是用来理解概率的，不是用来产生机密的。

为什么执着于可复现：实验室里最难受的事，是看到一个反常的偏差却没法再看一遍。
把种子摆到界面上、并可一键复用，比「再跑一次碰运气」有用得多。

## 性能与上限

| 限制 | 数值 | 理由 |
| --- | --- | --- |
| 单次试验总数 | 1 亿 | JS 在主线程上跑更多会让人以为界面死了；再大请拆成几步 |
| 轮数 | 100 万 | 「很多轮、每轮很少次」是看收敛的常用形态 |
| 图上点数 | 2000 | 超过就按固定步长抽样，并在图注与表格说明里写明 |
| 明细表行数 | 默认 100 行，可展开到抽样全部 | 避免一次挂上几千个 DOM 节点 |
| 逐次结果 | 5000 次 | 只用于「一发入魂」那条顺序带 |
| 理论分布 n | 5000 | 精确计算要算 n+1 个概率，5000 已经足够快 |

模拟是**分片**执行的：每片最多约 12ms，然后把主线程让出去。因此：

- 界面在跑 1 亿次时依然可以滚动、可以取消；
- 进度条更新被节流到约 90ms 一次，不会因为频繁 setState 拖慢模拟本身；
- 取消是立即的（会清掉待执行的定时器），并且**不保留部分结果** —— 半截样本的统计量
  虽然数学上有效，但它看起来像一次完整实验，容易被误读。

## 只申请一项权限：`storage`

存的东西只有三份草稿与一份设置：

| 存储键 | 内容 |
| --- | --- |
| `draft.batch` | 批量统计的轮数、每轮次数、概率、种子 |
| `draft.shot` | 一发入魂的轮次、概率、种子 |
| `draft.theory` | 理论分布的 n、k、概率 |
| `settings` | 置信水平（90 / 95 / 99） |

不声明其它任何权限：没有网络、没有文件、没有通知、没有剪贴板权限。
「复制摘要 / 复制 CSV」用的是页面自带的 `navigator.clipboard`，失败时会提示手动选中复制，
不会因此多申请一项权限。

卸载插件时这些数据随插件数据目录一起删除；想只清参数，点各标签页的「重置参数」。

## 界面

- 配色全部走宿主的 `--accent-*` 令牌并带兜底值，因此换主题色时会自动跟随；
- 深色模式用 `:root.dark`（不是 `prefers-color-scheme`），跟随应用里的主题开关；
- 图表是手写 SVG：曲线、波动范围、柱状图都是真正的 DOM 元素，缩放时不糊；
- 悬停曲线可以逐点读数；键盘焦点环、`aria-label`、`aria-live` 结果播报都补齐了；
- 窄窗口下概率预设会自动换行，参数区不会把内容区挤没。

## 目录结构

```
prob-lab/
├── manifest.json   清单：只声明 storage，runtime 为 sandboxed
├── index.js        手写 IIFE（无构建步骤），界面用宿主提供的 React
├── index.css       全部样式：浅色 / 深色 / 响应式 / 图表
├── icon.svg        图标：一条围绕期望值收敛的折线
├── README.md       这份文件，显示在插件详情里
└── LICENSE         MIT
```

打包与发布见[发布流程](../../docs/发布流程.md)：`node scripts/build.ts` 会把它打成
`dist/prob-lab/<版本>.lcp` 并重新生成 `index.json`。索引改动后必须用维护者的私钥重新签名，
否则客户端会验签失败。

## 实现上的几个取舍

1. **不用 `Math.random`。** 见「种子与可复现」。
2. **曲线用采样点，而不是每一轮一个 `div`。** 2000 个点以内的折线是一段 path，
   渲染成本与轮数无关；超出的部分按步长抽样，且抽样这件事在界面上写得清清楚楚。
3. **正常波动范围是梯形而不是带子。** 每轮的标准误不同，画成等宽带会误导人以为误差不随样本变化。
4. **限值报错而不是静默截断。** 超过 1 亿次会说「当前多少、上限多少、该怎么办」，
   而不是悄悄跑 1 亿次然后给一个看起来完整的结论。
5. **理论分布用对数伽马函数。** `C(5000, 2500)` 是一个 1500 位左右的数，直接算会溢出；
   在对数域里加减再取指数，n 到 5000 都稳。
6. **运行编号防竞态。** 取消之后立刻再点运行，上一轮还排在定时器队列里的分片回调
   会发现编号对不上而直接退出 —— 否则旧结果会覆盖新结果。
